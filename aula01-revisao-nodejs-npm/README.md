# 📚 Aula 01 — Revisão do Node.js e NPM
Nesta aula foi realizada uma revisão dos principais conceitos do Node.js e do NPM, com foco na execução de JavaScript no ambiente Server-Side e na preparação do ambiente inicial de desenvolvimento.

# 🎯 Objetivos da aula
Revisar os conceitos fundamentais do Node.js.
Compreender a execução do JavaScript no ambiente Server-Side.
Verificar se o ambiente de desenvolvimento está configurado corretamente.
Inicializar um projeto utilizando NPM.
Criar um script para diagnóstico do ambiente.
Trabalhar com importação de métodos e módulos.
# 🟢 Conteúdos abordados
1. Node.js no ambiente Server-Side
Foi revisado o conceito do Node.js como ambiente de execução JavaScript fora do navegador.

Diferentemente do JavaScript executado no navegador, o Node.js permite desenvolver aplicações que são executadas no lado do servidor (Server-Side).
