# Codificação Back-End

Repositório dedicado ao aprendizado e desenvolvimento de aplicações Back-End, reunindo estudos, exercícios, projetos práticos e experimentos relacionados à programação.

# Sobre o projeto
Este repositório faz parte da minha jornada de aprendizado em desenvolvimento Back-End.
Aqui você encontrará códigos e projetos desenvolvidos com o objetivo de aprimorar conhecimentos em:
Lógica de programação
Desenvolvimento Back-End
APIs e serviços
Bancos de dados
Autenticação e segurança
Arquitetura e organização de projetos
Boas práticas de programação
