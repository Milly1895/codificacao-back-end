# Configuração de Variáveis de Ambiente
Projeto desenvolvido em aula para demonstrar como utilizar variáveis de ambiente em uma aplicação Node.js, utilizando o pacote dotenv.

# Objetivo
O objetivo do projeto é aprender a:
Configurar variáveis de ambiente através de um arquivo .env;
Utilizar o pacote dotenv para carregar essas variáveis;
Acessar configurações através de process.env;
Definir uma porta padrão para a aplicação;
Validar a existência de uma chave de API;
Configurar a URL de conexão com o banco de dados;
Proteger informações sensíveis utilizando .gitignore.

# Tecnologias utilizadas
Node.js
JavaScript
dotenv
MongoDB

# Aprendizados
Durante a aula, foram trabalhados os seguintes conceitos:
Variáveis de ambiente;
Arquivo .env;
Uso do dotenv;
process.env;
Valores padrão para configurações;
Validação de configurações obrigatórias;
Conexão/configuração de banco de dados;
Boas práticas de segurança;
Utilização do .gitignore.
