# Sistema de Logs
Projeto desenvolvido durante a aula de Node.js, onde praticamos a criação e manipulação de arquivos utilizando os módulos nativos da linguagem.

# O que foi feito
Neste projeto criamos um sistema simples para registrar mensagens em um arquivo de log.

# Durante a atividade aprendemos a:
Trabalhar com módulos usando import e export;
Utilizar o fs/promises;
Criar pastas automaticamente;
Criar e escrever em arquivos;
Adicionar informações sem apagar os registros anteriores;
Trabalhar com caminhos usando o módulo path;
Utilizar async e await;
Tratar erros com try e catch;
Criar uma função para formatar os logs com data e hora.

# Funcionamento
A função salvarLogSystem() recebe uma mensagem e salva essa informação no arquivo system.log.
Antes de salvar, o programa verifica se a pasta logs existe. Caso não exista, ela é criada automaticamente.
A mensagem também recebe a data e o horário em que o log foi registrado

# Objetivo do exercício
O objetivo principal foi aprender a criar um sistema simples de registro de logs, utilizando recursos nativos do Node.js e praticando conceitos fundamentais de desenvolvimento backend.
